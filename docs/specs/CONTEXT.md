# Moost

AI コーディングエージェント（まず Claude Code）のセッションにメモを付けて記録し、ワンクリックでセッションへ復帰できるシステムトレイ常駐アプリ。名前は Memo + Roost（鳥の巣）に由来する。

## Language

**セッション**:
エージェント CLI との 1 回の対話単位。Claude Code では sessionId（UUID）で識別され、実体は `~/.claude/projects/` 配下のセッション JSONL。
_Avoid_: 会話、チャット

**セッションタイトル**:
セッションを一覧で識別するための自動導出された見出し。ai-title があればそれ、なければ最終プロンプト先頭 50 文字で代用する。人は編集しない。
_Avoid_: タイトル（単独では メモタイトル と紛らわしい）

**ai-title**:
Claude Code 自身がセッション JSONL に追記する `{"type":"ai-title","aiTitle":"..."}` 行。会話中に更新されるため最新の行を採用する。Moost が生成するものではない。

**メモ**:
人がセッションに付ける記録。メモタイトル・タグ・本文を持ち、復帰に必要な情報（sessionId・プロジェクトパス）を自己完結で抱える。同一セッションに複数付けられる。エージェント側ディレクトリではなく Moost 専用の人が読める保存先に置かれ、アプリを消しても残る。
_Avoid_: ノート

**メモタイトル**:
人がメモに付ける見出し。必須。新規作成時はセッションタイトルが初期値として自動入力される。セッションタイトル（自動導出）とは別物。

**登録プロジェクト**:
新規セッションを起動するためにユーザーが明示的に登録したディレクトリ。既存のセッション履歴とは無関係に、セッションが1件もない状態でも登録できる。一覧行やメモが持つ `projectPath`（復帰先の絶対パス文字列）とは別物で、ユーザーが「これは覚えておきたい起動先だ」と意思表示した1件のエンティティを指す。UI 上のタブ名は簡潔に「プロジェクト」と表示するが、概念としては本語を正式名とする。
_Avoid_: ディレクトリ登録、プロジェクトブックマーク、（単独の）プロジェクト

**直近セッション一覧**:
history.jsonl を sessionId 単位に集約して得る、最新順のセッション一覧。要約用フォークセッションはマーカーで除外される。

**復帰コマンド**:
セッションを再開するためのシェルコマンド。`cd <project> && claude --resume <sessionId>` の形に組み立てる。
_Avoid_: 再開コマンド、レジューム

**セッション要約**:
セッション詳細画面で実行する使い捨ての表示情報。永続化せず、アプリ常駐中のメモリキャッシュ（セッションID × 要約範囲がキー）のみに保持する。残したい要点は人がメモ本文へ書き移す。全体要約と直近要約の 2 モードがある。
_Avoid_: サマリー保存、要約メモ

**要約用フォークセッション**:
セッション要約のために `--resume --fork-session` で起こした使い捨てセッション。プロンプト先頭のマーカー文字列で直近セッション一覧から除外する。

**ポップオーバー**:
トレイアイコン直下に開く Moost の唯一のウィンドウ。クリックされたディスプレイのアイコン直下・中央揃えに現れ、フォーカスを失うと隠れる。固定サイズ・移動不可。常に 1 画面だけを表示する。
_Avoid_: メインウィンドウ、ダイアログ

**AgentAdapter**:
エージェント CLI ごとの差分（セッション履歴の場所とパース・セッションタイトル取得・復帰コマンド組み立て・ヘッドレス実行コマンド）を閉じ込める core パッケージの抽象インターフェース。第 1 弾の実装は Claude Code。
