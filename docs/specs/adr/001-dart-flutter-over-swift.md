# ADR-001: Swift 先行実装を Dart/Flutter で再構築する

- **ステータス**: Accepted
- **決定日**: 2026-07-09

## コンテキスト

Swift 製の先行実装（claude-session-memo）が macOS 上で既に動作している。
セッション一覧・ai-title 取得・メモ CRUD・要約・トレイ常駐 UI まで一通り検証済みで、
既知のハマりどころ（GUI の PATH 問題、パイプバッファのデッドロック等）も潰してある。

一方でプロダクトの射程は「OSS として公開し、将来は Windows/Linux でも動かす」であり、
Swift（AppKit/SwiftUI 依存）のままでは実質 macOS 専用になる。

## 決定

**動作している Swift 版を捨て、Dart/Flutter の monorepo（packages/core + apps/desktop）として再構築する。**

## 理由

クロスプラットフォーム対応のため。

| 観点 | Swift 継続 | Dart/Flutter 再構築 |
|------|-----------|--------------------|
| macOS | 動作済み | 再実装が必要 |
| Windows/Linux | 実質不可能（UI 全書き直し） | Flutter デスクトップで対応可能 |
| ロジック移植コスト | — | 低い（検証済みロジックの忠実な移植で済む） |
| トレイ常駐 | ネイティブで自然 | プラグイン依存（リスクは残る） |

再構築といっても設計・データ取得ロジック・ハマりどころの知見はすべて先行実装から引き継ぐため、
ゼロからの開発ではなく「検証済み仕様の移植」に近い。

## 影響

- Swift 版はプロトタイプ・リファレンス実装の位置づけになる
- UI 非依存ロジックを `packages/core`（pure Dart）に隔離することで、
  Flutter のデスクトップ対応状況に問題が出ても core は無傷で残る
